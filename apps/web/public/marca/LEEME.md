# Archivos del logo de Videollamada Animal

Generados el 05/11/2026 a partir del componente `components/Logo.tsx` (mismos trazos y colores) y de la tipografía Unbounded Bold (texto convertido a curvas, no depende de que la fuente esté instalada).

| Archivo | Para qué |
|---|---|
| `icono-oscuro.svg` | Solo el ícono, para fondos claros (vector) |
| `icono-claro.svg` | Solo el ícono, para fondos oscuros (vector) |
| `logo-completo-oscuro.svg` | **Logo completo** (ícono + VIDEOLLAMADA / ANIMAL), fondos claros (vector) |
| `logo-completo-claro.svg` | Logo completo para fondos oscuros (vector) |
| `icono-oscuro-1024-sobre-arena.png` | Ícono 1024 × 1024 con fondo arena, listo para tiendas y perfiles de redes |
| `icono-oscuro-1024-transparente.png` / `icono-claro-1024-transparente.png` | Íconos 1024 × 1024 con fondo transparente |
| `logo-completo-oscuro-2000.png` / `logo-completo-claro-2000.png` | Logo completo en PNG transparente de 2000 px de ancho |

Colores: ver `app/globals.css` y la página «Kit de marca» en Notion.

**Los archivos no incluyen ® ni ™.** El símbolo depende del estado del registro en el INPI y se agrega al usar el logo (en la plataforma lo controla `SIMBOLO_MARCA`).

Marca de Videollamada Animal únicamente: no se vincula con ninguna otra marca.
